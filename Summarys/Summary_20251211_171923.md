## Technische Details

### Firestore Collections
- `winehandel` - Neue Collection für Weinhandel-Unternehmen
  - Struktur ähnlich wie `wineries`
  - Felder: `name`, `ownerId`, `isVerified`, `region`, `address`, `description`, `images`, `createdAt`, `updatedAt`

### User-Felder (Firestore)
- `isWinehandel` - Boolean: User ist ein Weinhandel
- `isWinehandelVerified` - Boolean: Weinhandel ist verifiziert

### Verifizierungs-Flow
1. User registriert sich mit `isWinehandel: true`
2. Admin verifiziert User in User-Verwaltung → `isWinehandelVerified: true`
3. Wenn Weinhandel-Profil existiert, wird auch `isVerified: true` im Weinhandel-Profil gesetzt
4. Verifizierte Weinhandel-Unternehmen werden im WeinhandelScreen angezeigt
