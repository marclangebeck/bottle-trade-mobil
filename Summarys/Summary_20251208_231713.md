## Technische Details

### Build-Skript (`build.sh`)
```bash
#!/bin/bash
# Setze nvm-PATH
export PATH="$HOME/.nvm/versions/node/v20.19.6/bin:$PATH"

# Prüfe Node.js
if ! command -v node &> /dev/null; then
    echo "❌ Node.js nicht gefunden..."
    exit 1
fi

# Führe Build aus
npm run build
```
