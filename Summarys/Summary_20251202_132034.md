## KI-Konzept-Überblick

### Empfohlener Ansatz: Hybrid
- **Primär**: Google Cloud Vision API (hohe Genauigkeit)
- **Fallback**: Tesseract.js (kostenlos, offline)
- **NLP**: Regex-Patterns + Wein-Datenbank-Lookup

### Kosten
- Google Cloud Vision: Erste 1.000 Bilder/Monat kostenlos
- Danach: ~$1.50 pro 1.000 Bilder
- Tesseract.js: Kostenlos

### Implementierungs-Phasen
1. **Phase 1**: MVP mit Google Cloud Vision API
2. **Phase 2**: Tesseract.js Fallback hinzufügen
3. **Phase 3**: NLP-Verbesserung
