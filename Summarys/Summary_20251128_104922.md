## Technische Details

### Neue Datenstruktur
**Firestore: `wineries/{wineryId}`**
- `name`, `description`, `region`, `address`, `website`, `contactEmail`, `phone`
- `images` (Array, max. 5)
- `ownerId` (User UID)
- `isVerified` (boolean, wird von Admin gesetzt)
- `createdAt`, `updatedAt`

**Firestore: `users/{userId}`**
- `isWinery` (boolean, wird bei Registrierung gesetzt)
- `isWineryVerified` (boolean, wird von Admin gesetzt)

### Verifizierungs-Workflow
1. User registriert sich mit "Ich bin ein Weingut" → `isWinery: true`
2. Admin verifiziert User in User-Verwaltung → `isWineryVerified: true`
3. User kann jetzt Weingut-Profil erstellen/bearbeiten
4. Weingut-Profil wird in `wineries` Collection erstellt
5. Nur verifizierte Weingüter erscheinen in WeingueterScreen
