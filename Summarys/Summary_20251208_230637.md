## Neue Erkenntnisse

### nvm-Loading
- `~/.bashrc` ist korrekt konfiguriert (nvm wird geladen)
- Problem: In nicht-interaktiven Shells (Cursor) wird `.bashrc` nicht immer geladen

### GitHub Push Protection
- GitHub scannt automatisch nach Secrets in Commits
- Auch in alter Historie werden Secrets erkannt
- `git filter-branch` ist notwendig, um Secrets aus Historie zu entfernen
- Force-Push erforderlich nach Historie-Rewrite

### Agent Review
- GitHub's Code Scanning erkennt hardcodierte Credentials
- Auch Platzhalter wie "username:password" werden als potentielles Problem markiert
- Best Practice: Immer Umgebungsvariablen verwenden
